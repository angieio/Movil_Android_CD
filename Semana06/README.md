### Requerimientos funcionales

**Registro de usuario:** El sistema debe permitir registrar un usuario ingresando nombre completo, teléfono, dirección y referencia.

**Inicio de sesión:** El sistema debe permitir al usuario iniciar sesión mediante correo electrónico y contraseña.

**Visualización de productos:** El sistema debe mostrar los productos con su imagen, nombre, presentación y precio.

**Búsqueda de productos:** El sistema debe permitir buscar productos en tiempo real por nombre o descripción.

**Filtrado por categorías:** El sistema debe permitir filtrar los productos por categorías y combinar este filtro con la búsqueda.

**Agregar productos al carrito:** El sistema debe permitir agregar productos directamente desde la lista o desde el detalle.

**Visualización del detalle:** El sistema debe mostrar la imagen, nombre, presentación, descripción y precio del producto seleccionado.

**Selección de cantidad:** El sistema debe permitir aumentar o disminuir la cantidad de un producto antes de agregarlo al carrito.

**Gestión de favoritos:** El sistema debe permitir marcar y desmarcar productos como favoritos.

**Gestión del carrito:** El sistema debe permitir aumentar, disminuir y eliminar productos del carrito.

**Cálculo del pedido:** El sistema debe calcular automáticamente el subtotal, el costo de delivery de S/ 4.00 y el total.

**Registro de datos de entrega:** El sistema debe permitir ingresar y editar nombre, teléfono, dirección y referencia.

**Selección del método de pago:** El sistema debe permitir seleccionar entre efectivo al entregar, Yape y Plin.

**Confirmación del pedido:** El sistema debe mostrar la confirmación del pedido con su número, monto total y dirección de entrega.

**Finalización del pedido:** El sistema debe permitir consultar el estado del pedido o regresar al inicio y vaciar el carrito.
